1. Project Title
Sales Data Analysis & Power BI Dashboard
2. Short Description
Interactive sales dashboard developed in Power BI to analyze sales, quantity, profit, products, categories, payment methods, and sales trends.
3. Tech Stack
Power BI | Power Query | DAX | Excel/CSV | Data Visualization
4. Data Source
Sales transaction data containing information such as date, product, quantity, sale type, payment mode, discount, and selling value.
5. Features
📊 Total Sales, Quantity & Profit KPIs
📈 Monthly and daily sales analysis
🛍️ Product-wise sales analysis
📂 Category-wise sales analysis
💳 Payment mode analysis
🔄 Sales type analysis
🎛️ Interactive Year & Month filters
🎛️ Sale Type & Payment Mode slicers
📌 Profit and Profit % analysis
📊 Interactive Power BI visualizations
6. Example
Example:
The dashboard can be used by a business to identify:
Which products generate the highest sales
Which categories are performing well
Monthly and daily sales trends
Most-used payment methods
Profit and profitability trends
Example insight:
“The dashboard helps compare product-wise and category-wise sales and identify periods with higher sales performance.”
